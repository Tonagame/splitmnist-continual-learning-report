# Documentation Index

This folder contains the written documentation for the Split MNIST continual-learning project.

## Recommended Reading Order

1. [`SUBMISSION_CHECKLIST.md`](SUBMISSION_CHECKLIST.md) - maps every submission requirement to a file.
2. [`PROJECT_SCOPE.md`](PROJECT_SCOPE.md) - what the project reproduces and what is outside scope.
3. [`REPRODUCTION_REPORT.md`](REPRODUCTION_REPORT.md) - main results and conclusions.
4. [`ALGORITHMIC_THINKING.md`](ALGORITHMIC_THINKING.md) - algorithmic thinking and method logic.
5. [`PROJECT_STEPS.md`](PROJECT_STEPS.md) - detailed project stages.
6. [`TESTING_BY_STAGE.md`](TESTING_BY_STAGE.md) - validation and testing at each stage.
7. [`IMPLEMENTATION_AUDIT.md`](IMPLEMENTATION_AUDIT.md) - honesty check: what is fully implemented, partial, or experimental.
8. [`CODE_EXPLANATION.md`](CODE_EXPLANATION.md) - how the implementation works.
9. [`LSR_LITE_EXPLANATION.md`](LSR_LITE_EXPLANATION.md) - the LSR-lite prototype and its ablations.
10. [`PAPER_COMPARISON.md`](PAPER_COMPARISON.md) - detailed comparison with the paper and reference code.
11. [`AI_USAGE_REPORT.md`](AI_USAGE_REPORT.md) - explanation of AI usage during the project.
12. [`AI_PLAN_SUMMARY.md`](AI_PLAN_SUMMARY.md) - summary of AI-assisted planning.
13. [`AI_WORK_LOG.md`](AI_WORK_LOG.md) - short AI work log.
